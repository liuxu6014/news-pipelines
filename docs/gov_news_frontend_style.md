# 前端界面风格说明

这个文件用于记录当前前端页面的界面风格，方便后续保持一致。它只是说明文档，不参与网页运行，不会影响 `index.html` 和 `news_data.js`。

## 整体风格

当前前端是一个偏数据管理和新闻检索的工具界面，风格以简洁、清晰、实用为主。

- 页面不是宣传页，而是直接展示可筛选、可查看正文的数据表。
- 视觉重点放在新闻数据本身，不使用复杂装饰。
- 颜色克制，背景浅灰，内容区白色，适合长时间查看。
- 表格信息密度较高，方便快速扫描机构、日期、标题和正文长度。

## 页面结构

页面分为四个主要区域：

- 顶部筛选区：页面标题、搜索框、分类筛选、机构筛选、重置按钮。
- 统计区：展示新闻条数、覆盖机构、来源官网、采集时间。
- 新闻表格区：按行展示每条新闻的基础信息。
- 正文弹窗区：点击“查看正文”后显示完整新闻内容。

## 色彩风格

当前页面使用浅色数据后台风格。

主要颜色：

```css
--bg: #f6f7f9;       /* 页面浅灰背景 */
--panel: #ffffff;    /* 内容面板白色 */
--ink: #20242a;      /* 主文字颜色 */
--muted: #68707d;    /* 次要文字颜色 */
--line: #dfe3e8;     /* 边框线颜色 */
--accent: #1769aa;   /* 主按钮、链接蓝色 */
--accent-2: #0f766e; /* 正向状态颜色 */
--warn: #9a3412;     /* 警示状态颜色 */
```

视觉效果：

- 页面背景：浅灰色。
- 卡片和表格背景：白色。
- 表头：淡蓝灰色。
- 链接和主按钮：蓝色。
- 边框：浅灰色细线。

## 字体风格

字体使用系统中文优先字体，保证 Windows 和常见浏览器中显示清晰。

```css
font-family: "Microsoft YaHei", "PingFang SC", "Segoe UI", Arial, sans-serif;
```

字号风格：

- 页面基础字号：`14px`
- 页面标题：`22px`
- 统计数字：`21px`
- 弹窗标题：`18px`
- 次要说明文字：`12px`

整体文字不追求大标题视觉，而是适合数据阅读。

## 控件风格

搜索框、下拉框、按钮保持统一高度：

```css
height: 36px;
border-radius: 6px;
```

控件特点：

- 搜索框用于全文搜索。
- 分类和机构使用下拉筛选。
- 重置按钮使用蓝色主按钮样式。
- 表格中的“查看正文”按钮尺寸更小，避免干扰表格阅读。

## 表格风格

表格是页面核心区域。

设计特点：

- 表格最小宽度为 `1080px`，适合展示多列新闻字段。
- 表头固定，滚动时仍能看到列名。
- 行 hover 时背景变浅蓝灰，方便定位。
- 标题列设置最大宽度，避免长标题撑乱页面。
- 日期列固定宽度，方便纵向比较。

表格字段：

- 机构名称
- 分类
- 发布日期
- 新闻标题
- 来源栏目
- 官网链接
- 正文长度
- 正文按钮

## 弹窗风格

完整正文使用浏览器原生 `dialog` 弹窗展示。

设计特点：

- 最大宽度约 `920px`。
- 弹窗高度受视口限制，正文区域内部滚动。
- 背景遮罩为半透明深色。
- 正文使用较大的行高，便于阅读。
- 正文保留换行和空白显示：

```css
white-space: pre-wrap;
line-height: 1.75;
```

## 响应式风格

当屏幕宽度小于 `820px` 时：

- 页面左右内边距减小。
- 搜索和筛选工具栏改为单列。
- 统计区从四列变为两列。
- 表格区域取消固定最大高度，适配移动端滚动。

## 交互风格

交互保持直接、轻量：

- 输入搜索关键词后立即筛选。
- 修改分类或机构后立即筛选。
- 点击重置恢复全部数据。
- 点击新闻标题可打开原官网链接。
- 点击“查看正文”在当前页面弹窗中阅读完整正文。

## 后续修改建议

如果后续继续改前端，建议保持以下原则：

- 保持数据表为第一屏核心，不改成宣传页。
- 保持浅色、清晰、低装饰的数据工具风格。
- 不要把正文直接塞进表格单元格，继续使用弹窗。
- 新增筛选项时放在顶部工具栏。
- 新增统计指标时放入统计区，最多保持一行四项或移动端两列。
